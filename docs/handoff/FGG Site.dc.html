Design notes
Palette — pulled from the logo: sun yellow #FFE15A, aqua #33EEDC, bubblegum #FF7EB9, ink #141414. Warm white ground, lots of air.
Type — Fredoka for headings (rounded, bold, not babyish), Nunito for UI and body.
Sticker system — 2px ink outlines + hard offset shadows on buttons, event cards and badges = the "game piece" feel. Everything else stays flat and calm so the page never feels cluttered.
Assumptions — Today is Sep 30 2026. Halloween Fest Oct 24–25 (registration open); Holiday Fest Dec 12–13 (sold out); Spring / Summer / Harbor Fest 2027 (coming soon). Venues are placeholders. One table type: $200, or $100 for PokéBucks partners (bring a bulk binder, accept PokéBucks). XP from check-ins, challenges and raffles.
